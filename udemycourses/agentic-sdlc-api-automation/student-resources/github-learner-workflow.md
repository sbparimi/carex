# GitHub workflow for learners

1. Open the lesson's pinned checkpoint; download its ZIP or clone the repository.
2. Follow setup instructions and use synthetic demo data only.
3. Work on a local copy or separate branch; never commit secrets.
4. Run verification steps and save output locally.
5. Compare with expected results; diagnose failures before opening the solution.
6. Use the completed checkpoint to compare reasoning and implementation.

Never commit .env files, tokens, passwords, private keys or database URLs. Never run seed, migration or destructive test commands against production. Do not grant AI agents unrestricted repository write access.
