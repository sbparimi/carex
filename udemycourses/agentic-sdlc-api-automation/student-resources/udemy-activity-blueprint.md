# Udemy activity blueprint

## Lecture-level implementation
- Attach the lesson resource ZIP or concise downloads to the relevant lecture.
- Place native quizzes after the taught material; do not test untaught concepts.
- Use practical assignments after a demonstration and starter release.
- Add integrated section assessments after practical checkpoints.
- Link the exact GitHub checkpoint in the lecture description and resource index.

## Quiz quality
3–5 scenario-based questions; one best answer; plausible distractors; explanations; outcome mapping. Avoid trivia and trick wording.

## Assignment quality
State business context, task, deliverables, acceptance criteria and verification. Include starter, expected result and separate tested solution. Grade evidence and reasoning, not superficial similarity.

## Rhythm
Every lesson: learning activity. Every section: integrated checkpoint and section quiz. End: capstone and evidence-based rubric.
