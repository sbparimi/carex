# Student resources — download centre

This folder contains course-wide learner resources. Lesson-specific files remain inside each lesson's `assets/student-downloads/` folder.

## Student download catalogue

| Resource | Purpose | Release state |
|---|---|---|
| Course workbook | Track Agent Mode prompts, decisions, exercises and evidence | Draft |
| Environment setup guide | Prepare Postman, Agent Mode, Postman CLI, Git and GitHub Actions | Draft; account and version checks required |
| CareX starter project | Synthetic API under test and sample configuration | Existing application; student distribution package not yet assembled |
| Agentic API quality quick reference | Postman Agent Mode, collection, CLI, evidence and approval boundaries | Draft |
| Capstone project pack | Business brief, change request, OpenAPI contract, test data and learner tasks | Not assembled |
| Completed capstone solution | Completed project and expected evidence, released after learner attempt | Not assembled; instructor validation required |

## Download rules
1. Only include files learners need to perform or verify course tasks.
2. Never include production scripts, private instructor notes, internal acceptance scorecards or unreleased answer keys.
3. No real credentials, personal data, customer data or production database URLs.
4. Pin tool versions where reproducibility requires it; state when versions are intentionally flexible.
5. Provide a clean starter and completed checkpoint for every substantial project milestone.
6. Every file must have a clear filename, purpose, version and usage instruction.
7. Test every download from a clean learner environment before marking it released.

## Progression model
Learners work on one continuous CareX appointment-booking API project. Each section adds a capability and provides a checkpoint. Do not make learners recreate the project from scratch in every lesson.
