# Lesson 3.3 — Structured outputs, schemas and validation

**Section:** 03 — Agent Orchestration Architecture  
**Learner outcome:** Constrain an Agent Mode test proposal to a JSON contract and validate required fields, evidence references, allowed actions and release recommendation in Postman.

## Seven-part lesson
1. **Opening:** Introduce the CareX appointment-cancellation change and the workflow risk addressed in this lesson.
2. **Concept:** Explain the concept using Postman Agent Mode, Postman collections and evidence hand-offs.
3. **Why:** Connect the technique to traceability, safe API automation and controlled release decisions.
4. **Demo:** Demonstrate the technique in Postman Agent Mode using the CareX workspace and supplied change.
5. **Build:** Complete the linked practical assignment using the starter artefact.
6. **Verify:** Compare the result with expected criteria; introduce one failure or ambiguity and diagnose it.
7. **Recap:** Record the checkpoint and explain how it feeds the next lesson.
