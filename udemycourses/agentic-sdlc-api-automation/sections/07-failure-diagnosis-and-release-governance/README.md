# Section 07 — Failure Diagnosis and Release Governance

**Planned section:** 07 of 08  
**Lessons:** 4  
**Status:** Bespoke learner assessments authored; seeded execution and release-gate demonstration remain open.

## Learning outcome
Use Postman and Postman CLI evidence to diagnose API test failures, use Postman Agent Mode for bounded evidence-based analysis, and produce a release recommendation controlled by deterministic policy and authorised human approval.

## Lessons
- 7.1 — Capture useful execution evidence
- 7.2 — Classify product, test, data and environment failures
- 7.3 — Prevent an AI diagnosis from becoming an unchecked gate
- 7.4 — Produce a release recommendation with deterministic rules
