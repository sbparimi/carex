## Learning outcome
Deliver an evidence-driven Agentic SDLC workflow for a CareX appointment-cancellation change: use Postman Agent Mode for analysis and test proposals, review the changes, implement tests in Postman, execute with Postman CLI and GitHub Actions, diagnose a reproducible failure and prepare a human-owned release assessment.

## Lessons
- 8.1 — Understand the CareX appointment-booking journey
- 8.2 — Introduce a business-rule change
- 8.3 — Run requirement, impact and test-planning stages
- 8.4 — Review collection changes and execute CI
- 8.5 — Triage a seeded failure and produce the release assessment

## Capstone release conditions
- Dedicated disposable non-production database branch confirmed.
- No shared preview/production database writes.
- Requirement, OpenAPI, Agent Mode output, collection diff, Postman/CLI run and CI evidence linked.
- Exact 24-hour boundary, ownership and staff-permission regression covered.
- Failure diagnosis is evidence-backed.
- Mandatory deterministic gates pass; final approval remains with an authorised human.
- Full clean-checkout run and learner rehearsal completed.
