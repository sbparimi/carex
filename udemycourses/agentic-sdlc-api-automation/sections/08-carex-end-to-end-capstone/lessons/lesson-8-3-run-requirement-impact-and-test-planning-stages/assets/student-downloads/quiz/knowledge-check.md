# Knowledge check — Lesson 8.3: Run requirement, impact and test-planning stages

Choose the single best answer.

1. **Which scenario is mandatory for the strict time rule?**
   - A. Exactly 24 hours before appointment start
   - B. Only 7 days before
   - C. Only a successful booking
   - D. A clinic health request

2. **The impact agent proposes an API operation not present in OpenAPI. What should the learner do?**
   - A. Add it to the collection
   - B. Mark it unsupported and ask for evidence/clarification
   - C. Assume it is hidden
   - D. Change the requirement

3. **What must the test plan include before collection changes?**
   - A. Only test names
   - B. Requirement IDs, source evidence, actor, preconditions, expected business outcomes and open questions
   - C. A release approval
   - D. Credentials

## Answer key and explanations
1. **A.** The exact boundary distinguishes > from >=.

2. **B.** Impact mapping must be contract-grounded.

3. **B.** A reviewed traceable plan is the hand-off to implementation.
