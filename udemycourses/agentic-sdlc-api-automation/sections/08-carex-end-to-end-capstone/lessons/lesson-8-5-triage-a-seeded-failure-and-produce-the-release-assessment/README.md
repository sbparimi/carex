# Lesson 8.5 — Triage a seeded failure and produce the release assessment

**Section:** 08 — CareX End-to-End Capstone  
**Learner outcome:** Diagnose a reproducible capstone failure from Postman/CLI evidence, compare Agent Mode's analysis with deterministic gates and produce a human-owned release recommendation.

## Seven-part lesson
1. **Opening:** State the capstone change, business impact and evidence required.
2. **Concept:** Explain the stage and how it connects to previous capstone work.
3. **Why:** Connect the stage to traceability, API quality and release confidence.
4. **Demo:** Demonstrate the relevant Postman Agent Mode, Postman collection, CLI or CI workflow using the CareX project.
5. **Build:** Complete the capstone task using the existing learner checkpoint.
6. **Verify:** Compare output with the approved requirement, contract and expected evidence; diagnose one failure.
7. **Recap:** Save the checkpoint and hand off to the next capstone stage.
