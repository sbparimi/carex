# Lesson 4.2 — Generate positive, negative and boundary scenarios

**Duration:** 25 minutes  
**Learner outcome:** Generate and review a complete scenario matrix covering positive, negative, exact-boundary, just-under, just-over, ownership, staff-role, state and timezone cases.

## Seven-part lesson
1. **Opening — 2 min:** Predict what should happen at exactly 24 hours.
2. **Concept — 4 min:** Explain equivalence partitions and boundary-value analysis.
3. **Why — 3 min:** Connect missing boundary and actor cases to escaped business defects.
4. **Demo — 6 min:** Generate scenarios with Postman Agent Mode and deliberately inspect a proposal that omits the exact boundary.
5. **Build — 5 min:** Complete the scenario matrix using the provided CSV seed.
6. **Verify — 4 min:** Compare against the reference matrix; mark HTTP expectations unverified without contract evidence.
7. **Recap — 1 min:** Hand the reviewed matrix to Lesson 4.3 for risk ranking.
