# Postman Agent Mode prompt — Lesson 4.3

Using the CareX change fixture, the reviewed scenario matrix and regression-candidates.csv, propose a risk-based regression order.

Use the scoring model in the expected-results guide: impact 40%, change proximity 30%, blast radius 20%, likelihood 10%. Explain each dimension and confidence. Treat likelihood as judgement, not measured probability. Keep all evidence states visible.

Do not invent traffic volumes, incident rates, customer counts, failure probabilities or production metrics. Do not use endpoint count as a proxy for risk. Separate direct change coverage from adjacent smoke coverage. Explain exclusions and what evidence would change the ranking.

Return a ranked CSV, rationale, uncertainty notes and a proposed first-pass regression scope. Do not edit the Postman collection or execute requests.
