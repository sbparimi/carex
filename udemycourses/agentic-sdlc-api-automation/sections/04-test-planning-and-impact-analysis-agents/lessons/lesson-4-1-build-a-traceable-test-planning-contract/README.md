# Lesson 4.1 — Build a traceable test-planning contract

**Duration:** 20 minutes  
**Learner outcome:** Produce a structured, source-linked API test-plan proposal and identify when missing contract evidence blocks execution.

## Seven-part lesson
1. **Opening — 2 min:** Predict the evidence needed to test a rejected patient cancellation.
2. **Concept — 3 min:** Distinguish requirement, collection, OpenAPI and runtime evidence.
3. **Why — 2 min:** Explain how invented response expectations create false confidence.
4. **Demo — 5 min:** Use Postman Agent Mode in proposal-only mode with the CareX fixture, evidence register, JSON schema, collection and pinned OpenAPI document.
5. **Build — 4 min:** Generate a test-plan proposal with scenario IDs, evidence references, risk and open questions.
6. **Verify — 3 min:** Reject unsupported status and response-field claims; reconcile the proposed 24-hour rule with the current 120-minute code default.
7. **Recap — 1 min:** Hand the traceable plan to Lesson 4.2 and Section 5.
