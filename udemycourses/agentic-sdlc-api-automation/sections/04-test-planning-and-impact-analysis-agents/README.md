# Section 04 — AI-assisted Test Planning and Impact Analysis

**Planned section:** 04 of 08  
**Lessons:** 4  
**Status:** Bespoke learner assessments authored; runnable demonstrations remain in production.

## Learning outcome
Use Postman Agent Mode to propose traceable, risk-based API test scenarios from CareX business requirements and the OpenAPI contract. Review generated scenarios for coverage, unsupported assumptions and weak assertions before implementing them in Postman.

## Lessons
- 4.1 — Build a traceable test-planning contract
- 4.2 — Generate positive, negative and boundary scenarios
- 4.3 — Prioritise regression by business impact
- 4.4 — Review hallucinations, omissions and weak assertions

## Carry-forward artefact
A human-reviewed, source-linked test plan with risk ranking and open questions, ready for Postman collection implementation in Section 5.
