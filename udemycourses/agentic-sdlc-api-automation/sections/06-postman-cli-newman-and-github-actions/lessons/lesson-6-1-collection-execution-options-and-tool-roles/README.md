# Lesson 6.1 — Collection execution options and tool roles

**Section:** 06 — Postman CLI and GitHub Actions  
**Learner outcome:** Choose the correct execution surface for Postman Agent Mode, Postman app, Postman CLI, GitHub Actions and legacy Newman.

## Seven-part lesson
1. **Opening:** Show why a reviewed Postman collection must run consistently outside the desktop app.
2. **Concept:** Explain the role of the relevant execution and CI tools.
3. **Why:** Connect repeatability, failure visibility and secure automation to release confidence.
4. **Demo:** Demonstrate the current official Postman workflow and inspect actual output.
5. **Build:** Complete the lesson assignment using the CareX collection.
6. **Verify:** Run a positive case and a deliberate failure; inspect exit status and retained evidence.
7. **Recap:** Carry the pipeline and evidence into failure diagnosis and release governance.
