# Lesson 1.1 — The limits of conventional API automation

**Section:** 01 — Agentic SDLC and API Quality Engineering  
**Learner outcome:** Compare a conventional manually maintained API test workflow with a Postman Agent Mode-assisted workflow, and identify where human review and deterministic verification remain necessary.

## Seven-part lesson
1. **Opening:** Start with a CareX cancellation rule change that requires updates across requirements, API tests and regression.
2. **Concept:** Explain the limits of manually maintained collections, static test coverage and disconnected hand-offs.
3. **Why:** Show how change impact, test maintenance and evidence gaps create release risk.
4. **Demo:** Compare a manually updated Postman request/test with an Agent Mode proposal for the same change.
5. **Build:** Use the starter change brief and coverage-gap template to identify the work an agent could accelerate.
6. **Verify:** Check the proposed work against the source requirement and distinguish generated suggestions from executed API evidence.
7. **Recap:** Identify where Agent Mode helps and where Postman assertions and human review remain mandatory.
