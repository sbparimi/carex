# Student downloads — Lesson 1.2

This is the learner-facing download index for this lecture. It is intended to be visible in the course's downloadable resources, not as an instructor production folder.

## Before the lesson

- Download `responsibility-matrix.csv` and `scenario-release-conflict.json`.

## Downloads

- `responsibility-matrix.csv` — complete the ten responsibility classifications.
- `scenario-release-conflict.json` — synthetic report fixture for the release-gate exercise.
- `lesson-1.2-quick-reference.md` — one-page responsibility boundary reference.
- `lesson-1.2-exercise.md` — learner instructions and submission checklist.
- `lesson-1.2-answer-key.md` — completed answer; open only after attempting the exercise.

## Learner usage

1. Save a working copy of the starter files before editing.
2. Follow the exercise in the lecture.
3. Pause at prediction checkpoints and write down your expected result.
4. Run the supplied verification steps independently.
5. Compare with the checkpoint and open the answer key only after your attempt.
