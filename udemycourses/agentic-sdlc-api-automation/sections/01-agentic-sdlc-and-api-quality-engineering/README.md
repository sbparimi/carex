# Section 1 — Agentic SDLC and API Quality Engineering

**Learner checkpoint:** Complete Lessons 1.1–1.4, their individual knowledge checks and assignments, then complete the integrated section assessment.

## Learning progression
1. Identify the limits of conventional API automation.
2. Separate agent reasoning, deterministic execution and human accountability.
3. Design a reference architecture with typed hand-offs, evidence and gates.
4. Predict and contain unsafe autonomy.
